# AIGTM

Frontrunner (usefr.com, YC F26) を徹底調査し、**10倍良い AI-native GTM OS** を作るプロジェクト。

- フェーズ1: 社内の GTM/営業ワークフローを AI エージェント化（実績 = 最強の case study）
- フェーズ2: 外販可能なマルチテナント SaaS へ

決定的な違い: Frontrunner は既存 CRM の上に乗るエージェント層。**我々はアプリケーション層（SoR/受信/送信）ごと AI-native に内製する。**
